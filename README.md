I created this tool to fix dumps for apex legend, as Denuvo breaks / corrupts a lot of the games functions which in turn hides string locations, ect even with the process running and the processes pages / sections decrypted. To use this tool you will need to do a dynamic dump on a process using Denuvo, then run it through with the correct arguments, for a new fixed dump.

Note: This tool was built of the version of Denuvo Apex Legends uses

usage:
```
Denuvo_reBuilder.exe C:\\Path_To_Dump -o  C:\\Path_To_Output
```
Output: New PE File & IDA Python Script
