I created this tool to fix dumps for apex legend, as Denuvo breaks / corrupts a lot of the games functions, strings, classes ect even with the process running and the processes pages / sections decrypted. To use this tool you will need to do a dynamic dump on a process using Denuvo, then run it through with the correct arguments, for a new fixed dump.

Note: This tool was built of the version of Denuvo Apex Legends uses
